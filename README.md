# What Is This?
A while ago I had the idea to simulate an image redshifting. I already had pretty good shader knowledge, I just needed to use that knowledge for something

# What's The Presentation For?
Me and a few friends from college would occasionally hold presentation nights, where we would all make a presentation about something we liked, and shared it to everyone else. I actually made this project specifically for the presentation night! Gave me a definitive deadline instead of pushing it off

# What You'll Find

"Real Time Demo.html" is an unfinished project where I wanted to simulate redshifting occuring with a simplified simulation of the solar system. This was not completed in time for the presentation night. perhaps some day I will get back to this problem
